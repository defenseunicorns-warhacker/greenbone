Greenbone OpenVAS Integration

Security scanning workflow for Kubernetes

Software Delivery + Live Infrastructure Scanning
Current Workflow
Packaging
Zarf Package
Container image and Helm chart are bundled into a Zarf package for airgapped delivery into classified environments.
Static Scanning
Trivy · Grype · ClamAV · OpenSCAP
CVE scanning on container layers, malware checks, and OS-level compliance audits run against the Zarf package before deployment.
Compliance
CAT Review
An ISSM reviews the static scan report inside the Compliance Authorization Tool and grants an ATO before deployment proceeds.
Runtime
K8s Production
Once approved the package runs in the production cluster. No live infrastructure scanning occurs under the current workflow.
What's New
New
OpenVAS on Kubernetes
Greenbone Community Edition runs inside the production cluster and continuously scans the underlying node infrastructure for open ports, running services, and CVEs.
New
Bidirectional CAT Integration
OpenVAS pushes live scan results into the CAT tool. The CAT tool can trigger new scans on demand via the OpenVAS REST API, creating a continuous feedback loop.
Enhanced
Runtime Posture Review
ISSMs can now validate the live cluster security posture — open ports, running services, exposed interfaces — against what was approved at ATO time.
New
OpenVAS REST API
A FastAPI wrapper exposes GVM over HTTPS inside UDS. Targets, scans, and reports are accessible via standard JSON endpoints, ready for CAT tool integration.
